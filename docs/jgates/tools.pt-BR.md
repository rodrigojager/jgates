# Catálogo de ferramentas do JGates

As tabelas cobrem as verificações integradas. As versões das ferramentas com descritor vêm da imagem de ferramentas fixada. Consulte a [matriz de compatibilidade](compatibility.pt-BR.md) para ver as evidências de teste e os [avisos de terceiros](../../THIRD_PARTY_NOTICES.md) para ver o inventário completo da imagem, incluindo ambientes de execução e componentes incluídos.

## Ferramentas com descritor

O perfil Essencial roda as verificações básicas. O Equilibrado acrescenta as ferramentas aplicáveis do nível `main` desta tabela e o Rigoroso, as do nível `extended`. Use `tool:<id>` para ligar uma ferramenta explicitamente. A coluna de templates mostra o ID na origem integrada.
