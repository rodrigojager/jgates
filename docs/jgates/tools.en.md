# JGates tool catalog

The tables cover the built-in checks. Versions shown for descriptor tools come from the pinned tools image. See the [compatibility matrix](compatibility.en.md) for test evidence and [third-party notices](../../THIRD_PARTY_NOTICES.md) for the complete image inventory, including runtimes and bundled components.

## Descriptor-based tools
